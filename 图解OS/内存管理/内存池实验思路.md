# 内存池实验思路



按照教材定义，分为边界块、空闲块头结构、```MemoryPool```类框架

## 边界块

```c++
struct BlockBorder {
  int Blocklength;
  bool isfree() {
    if (Blocklength > 0) {
      return true;
    } else {
      return false;
    }
  }
  int MemorySize() {
    if (Blocklength > 0) {
      return Blocklength;
    } else {
      return -Blocklength;
    }
  }
  int BlockSize() { return MemorySize() + 2 * sizeof(BlockBorder); }
};
```



定义边界块以方便前后查询删改操作。

```Blocklength```携带两个信息：

1.可用内存大小；

2.是否占用；

```isfree()```函数表示是否空闲；

```MemorySize()```函数获取可用内存；

```BlockSize()```函数返回整个边界（含头）总内存。

## 空闲块头结构

```cpp
struct FreeBlockHead : public BlockBorder {
  FreeBlockHead *prior;
  FreeBlockHead *next;
};
```

```FreeBlockHead```继承```BlockBorder```类型表示为空闲部分；

```prior```指针指向前方（左侧）；

```next```指针指向后方（右侧）。

## ```MemoryPool```类框架

在```private```中，我们设置以下成员：

```cpp
private:
  char *Base;
  unsigned int PoolSize;
  FreeBlockHead *First;
```

其中，```Base```代表内存池基址（起始地址）；

```PoolSize```代表内存池容量；

```First```为空闲链表头节点；

### 初始化

```cpp
MemoryPool(unsigned int size) {
    PoolSize = size;
    Base = new char[PoolSize];
    // 申请大块内存空间
    First = (FreeBlockHead *)Base;
    First->Blocklength = size - 2 * sizeof(BlockBorder); // 实际可用空间
    First->prior = nullptr;
    First->next = nullptr; // 此时前后无相邻空闲块
    SetUsedBorder(Base, First->Blocklength);
  };
```

一开始申请时，还没有其他内容，所以先用```nullptr```指向；

因为在内存池中，我们使用了这个边界，所以，我们要减掉这个边界的大小：使用```sizeof()```函数。

```SetUsedBorder```是对这块空间的状态设置，稍后会提到。

### 析构

```cpp
~MemoryPool() { delete[] Base; };
```

这个没啥好讲的，直接```delete```就完事了。

### ```allocate()```函数

```cpp
void *allocate(int size) {
    FreeBlockHead *current = First;
    while (current && current->Blocklength < size) {
      current = current->next;
    }
    if (!current) {
      return nullptr;
    }
    int remain = current->Blocklength - size - 2 * sizeof(BlockBorder);
    if (remain > (int)sizeof(BlockBorder)) {
      SpiltBlock(current, size);
    } else {
      DeleteFreeBlock(current);
      current->Blocklength = -current->Blocklength; // 表示占用
    }
    return (char *)current + sizeof(BlockBorder);
  }; // 最先拟合策略
```

这是第一种策略：最先拟合策略。核心思路就是依次找，找到一个比```size```大的就直接分配内存。

但是有一个注意点：如果我们找到的这块内存的大小在减去```size```后剩下的还不够放下一个指针，那这块内存我们就用不了了，没用了。

所以我们不如把这块内存全部给出去。

这里的实现思路是用```remian```来查看：
如果可以放下指针，也就是我们的边界，那就调用```Splitblock()```函数进行切割；

反之，我们直接就删去这块空内存（表示占用了），即调用```DeleteFreeBlock()```函数。

```cpp
void *allocate_two(int size) {
    FreeBlockHead *current = First;
    FreeBlockHead *bestmin = nullptr;
    int min = INT_MAX;
    int remain;
    while (current) {
      remain = current->Blocklength - size - 2 * sizeof(BlockBorder);
      if (remain == 0) {
        bestmin = current;
        break;
      }
      if (remain < min) {
        min = remain;
        bestmin = current;
      }
      current = current->next;
    }
    if (bestmin) {
      if (remain > (int)sizeof(BlockBorder)) {
        SpiltBlock(current, size);
      } else {
        DeleteFreeBlock(current);
        current->Blocklength = -current->Blocklength; // 表示占用
      }
      return (char *)bestmin + sizeof(BlockBorder);
    }
    return nullptr;
  }; // 最优拟合策略
```

这里是第二种策略：最优拟合策略。核心思想就是先遍历，看能不能找到最不浪费的内存块。

所以我们要维护多个变量来进行查找，其余思路和第一个没太大区别。

### free()函数

```cpp
void free(void *p) {
    if (!p) {
      return;
    }
    FreeBlockHead *current = (FreeBlockHead *)((char *)p - sizeof(BlockBorder));
    current->Blocklength = abs(current->Blocklength);
    TryMerge(current);
  };
```

这个思路是这样的：我们先找到```p```所在部分的开头边界部分，这里有个注意点，就是我们要进行强制的类型转换；

因为我们对于地址的运算是字节级的，如果是我们定义的类的话就太大了；

这个不会自动转化，所以我们要强制转化。

```Blocklength```由负变正表示现在不被占用了。

最后```TryMerge()```一下，合并左右的小空快，以防止太过零碎。

### 一些辅助函数

与之前那些公有接口不同，这些函数是辅助用的，一般存在```private```内。

### ```SetUsedBorder()```函数

```cpp
void SetUsedBorder(void *p, int size) {
    ((BlockBorder *)p)->Blocklength = size;
    BlockBorder *tail =
        (BlockBorder *)((char *)p + sizeof(BlockBorder) + abs(size));
    tail->Blocklength = size;
  };
```

这个函数的作用是设定头尾边界；

设定这个边界是为了方便前后的查找等操作。

#### ```InsertFreeBlock()```与```DeleteFreeBlock()```函数

```cpp
void InsertFreeBlock(FreeBlockHead *p, int size) {
    p->next = First;
    p->prior = nullptr;
    if (First) {
      First->prior = p;
    }
    First = p;
  };
void DeleteFreeBlock(FreeBlockHead *p) {
    if (p->prior) {
      p->prior->next = p->next;
    } else {
      First = p->next;
    }
    if (p->next) {
      p->next->prior = p->prior;
    }
  }
```

这个的思路很简单，就是看这块空间是否空的，空的就插入头节点，不空的就删掉。

#### ```Getpreblock()```、```Getnextblock()```、```Getcurrentblock()```函数

```cpp
BlockBorder *Getpreblock(BlockBorder *p) {
    BlockBorder *prior_a = (BlockBorder *)((char *)p - sizeof(BlockBorder));
    if ((char *)prior_a <= Base) {
      return nullptr;
    }
    return (BlockBorder *)((char *)p - prior_a->BlockSize());
  };

  BlockBorder *Getnextblock(BlockBorder *p) {
    char *next_one = (char *)p + p->BlockSize();
    if (next_one >= Base + PoolSize) {
      return nullptr;
    }
    return (BlockBorder *)next_one;
  };

  BlockBorder *Getcurrentblock(void *p) {
    return (BlockBorder *)((char *)p - sizeof(BlockBorder));
  };
```

这个的核心思路就是对内存指针地址进行加减法，并且要注意边界。

举个例子，获取左边的地址时，我们先进行越界，获取左边的后边界。因为我们在```SetUsedBorder()```函数中写入了这个数据，所以我们可以直接读取了。

最后别忘了再强制转换成```BlockBorder*```，这个才是我们要的（头部地址，带边界）。

#### ```SpiltBlock()```和```TryMerge()```函数

```cpp
void TryMerge(BlockBorder *p) {
    BlockBorder *_next = Getnextblock(p);
    if ((char *)_next < Base + PoolSize && _next->isfree()) {
      DeleteFreeBlock((FreeBlockHead *)_next);
      int newsize =
          p->Blocklength + _next->Blocklength + 2 * sizeof(BlockBorder);
      p->Blocklength = newsize;
      SetUsedBorder(p, newsize);
    }
    BlockBorder *_prior = Getpreblock(p);
    if ((char *)_prior > Base && _prior->isfree()) {
      DeleteFreeBlock((FreeBlockHead *)_prior);
      int newsize =
          p->Blocklength + _prior->Blocklength + 2 * sizeof(BlockBorder);
      p->Blocklength = newsize;
      SetUsedBorder(_prior, newsize);
      p = _prior;
    }
    InsertFreeBlock((FreeBlockHead *)p, p->Blocklength);
  };

  void SpiltBlock(FreeBlockHead *p, int size) {
    int oldsize = p->Blocklength;
    int remain = p->Blocklength - size - 2 * sizeof(BlockBorder);
    DeleteFreeBlock(p);
    p->Blocklength = -p->Blocklength;
    FreeBlockHead *remainblock =
        (FreeBlockHead *)((char *)p + size + 2 * sizeof(BlockBorder));
    remainblock->Blocklength = remain;
    BlockBorder *remainblock_footer =
        (BlockBorder *)((char *)remainblock + remain + sizeof(BlockBorder));
    remainblock_footer->Blocklength = remain;
    InsertFreeBlock(remainblock, remain);
  };
```

这两个函数是分割和合并函数。

顾名思义，分割内存和合并（碎片）内存。

先看合并：
不管是右合并还是左合并，其本质都是一样的。

先用之前定义的辅助函数找到，然后，检查一下边界条件。

```cpp
int newsize =
          p->Blocklength + _prior->Blocklength + 2 * sizeof(BlockBorder);
```

这个先合并一下内存，注意一下，合并之后中间的边界就没了，要把这部分加上去。

然后我们更新一下条件：
```cpp
      p->Blocklength = newsize;
      SetUsedBorder(_prior, newsize);
```

注意一下：我们要的是头节点，所以在合并前面的时候别忘了把```p```指针也更新一下。

再看分割：
先用```remian```记录剩下内存，接着删去被割出去的部分（标记为非空）。

剩下的部分思路还是一样的：维护更新一下边界部分就行了。

最后别忘了把剩下的部分插入头节点，接着再用。
